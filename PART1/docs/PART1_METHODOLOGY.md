# Part 1 Methodology

This pipeline uses Yahoo Finance `^NSEI` as one NIFTY 50 index time series, not 50 separate constituent stocks. It removes duplicate dates, missing OHLC rows and invalid OHLC values. Predictors include daily/log returns, SMA/EMA ratios, MACD ratio, rolling volatility, intraday range, open-close return, RSI-14 and calendar features; volume is retained in the raw and cleaned datasets for inspection and EDA, but excluded from model predictors because reported index volume is inconsistent. Regression target is the next observed trading session close-to-close return. Classification target is 1 for a positive return and 0 for zero/negative return. The time-ordered data is split approximately 70% train, 15% validation and 15% test without shuffling. To prevent target leakage, boundary rows whose next-day target falls into the following partition are purged; two rows are excluded in total. Retain the raw CSV and run summary for reproducibility.
